# VINCI

Landing page institucional para a marca VINCI, desenvolvida com React, TypeScript e Vite.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Como executar

```bash
npm install
npm run dev
```

Acesse a URL exibida no terminal para visualizar a página localmente.

## Build de produção

```bash
npm run build
npm run preview
```

## Publicação

O projeto já está configurado para deploy via GitHub Pages com workflow automatizado.
